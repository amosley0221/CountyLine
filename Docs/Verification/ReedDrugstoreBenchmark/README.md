# PC rendered review — Reed and drugstore

These are actual 1280×720 Unreal PC captures from the final corrected review, not concept images or physical Android screenshots.

- `ReedAppearance`, `ReedPortrait`: idle silhouette, facial profile and corrected neck.
- `ReedWalk`, `ReedJog`: existing locomotion animations on the new mesh.
- `ReedMobileLOD`: a deliberately forced LOD 1 close-up on PC. It exposes hat-band and coat-detail simplification. Android keeps LOD 0 available; this filename does not establish the phone's selected LOD or appearance.
- `DrugstoreDisplay`, `CourtStreetShops`: the revised drugstore within the accepted street layout.

Remaining art work includes angular shoulder/coat forms, final likeness, facial rigging, detailed skin/cloth and full animation review. Phone acceptance should include the same locations, turning/walking/jogging, pause/resume and sustained play. Packaging success alone is not a performance or thermal result.
