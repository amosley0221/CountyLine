# Prototype asset register

## Included in the project

- `Content/Mannequin`: Epic Unreal Engine template mannequin, skeleton, materials, and locomotion, copied from the locally installed UE 5.8.2 `Templates/TemplateResources/Standard/Mannequin/Content`. These remain Epic content governed by the applicable Unreal license. Temporary player representation only; not Reed's final appearance.
- `Content/Prototype/Materials`: simple original flat-color materials generated by the repository script.
- `Content/Maps/L_JailOffice`: generated original office graybox, using Unreal Engine BasicShapes.
- `Content/UI/Fonts/OldStandardTT-Regular.ttf`: Old Standard, from Google Fonts `ofl/oldstandardtt/OldStandard-Regular.ttf`.
- `Content/UI/Fonts/CourierPrime-Regular.ttf`: Courier Prime, from Google Fonts `ofl/courierprime/CourierPrime-Regular.ttf`.
- `Content/UI/Fonts/Caveat.ttf`: Caveat variable font, from Google Fonts `ofl/caveat/Caveat[wght].ttf`.
- Font source: https://github.com/google/fonts. Each font's SIL Open Font License text is included alongside it. Runtime text uses these files directly.

## User-supplied references, not production character assets

The Design Bible and character/car JPGs are in the sibling workspace folder `The County Line`. They guide appearance and content. Photos/concept images are not rigged game meshes.

Ten FBXs in the workspace `Animations` folder identify themselves as Mixamo `MotionOnlyScene` exports with `mixamorig` bones and no vertex geometry: Walking, Walking (1), Jog Forward, Running, Fast Run, Drunk Run Forward, Driving, Entering Car, Exiting Car, Honking Horn. They have not been imported or silently substituted for the template animation set. The ZIP `Male Drunk Pack.zip` is preserved untouched.

Next animation step: obtain or author Reed's rigged skeletal mesh, confirm the animation source/usage rights, import against a matching Mixamo skeleton or retarget through an Unreal IK rig, and validate scale, feet, root motion, and in-place movement. No animation asset was modified in the source folder.
